# Komentář k zákonu č. 151/2025 Sb., o dávce státní sociální pomoci

Odborný komentář k **zákonu č. 151/2025 Sb., o dávce státní sociální pomoci (DSSP)** — reformní „superdávce“, která slučuje přídavek na dítě, příspěvek na bydlení a dávky pomoci v hmotné nouzi do jedné testované dávky se složkami na živobytí, bydlení a dítě a s pracovním bonusem. Nový zákon — judikatura k němu dosud neexistuje; navazuje na sesterské komentáře SSP-117-1995 a PHN-111-2006.

Konsolidované znění: dokument e-Sbírky `SB-2025-00151_2026-03-31`.
